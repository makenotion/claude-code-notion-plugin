# Build a semester study desk

Bring course choices, the next academic action, and actual upcoming deadlines
onto the first screen. Use a quiet subject palette and purposeful colored icons.
For a single reading seminar, use the [notebook layout](design.md).

## Compose the first screen

Set the semester home to full width. Place a compact navigation or contents row
beneath the title. Use a narrow side rail for reminders and useful capture
actions, and give the main area to courses and assignments. Keep the rail's
labels short and its controls real: add an assignment, open notes, or capture a
question. Place the current priority beside the working material it belongs to.

Show courses as compact gallery cards in the main area. Give each course a
recognizable subject icon, a useful next-assignment summary, and a route to its
notes and briefs. Use a consistent card size and readable wrapped text; expose
only the properties that help a learner decide where to start. Derive upcoming-assignment
summaries from related assignments. Label static summaries with their update date and explain that they do not
update automatically.

Place the Upcoming assignment table directly below the course gallery. Show
title, course, due date, and status; size columns so dates and titles remain
readable. Provide calendar, completed, and undated views without creating a new
copy of the assignments. Keep the weekly planning section and longer guidance collapsed
below the working area. Use source dates, not decorative progress figures.

Balance the rail, card row, and table so course choices and upcoming work are
visible together. On narrower screens, preserve a sensible reading order and
access to each surface; do not substitute a directory of links for course cards
or a static summary for the assignment database.

## Connect the learning material

Relate courses and assignments natively. Fill each course with its brief, useful
notes, and related work. Fill each assignment with the actual brief, deliverable,
criteria, and a sensible next step. Preserve equations and source references.
Offer suggested study questions without solving graded assignments when the
request is organization.

Carry each course's visual identity into its pages and mentions. Keep original
material accessible, and use clear headings and generous reading space inside
notes. Choose a relevant cover or illustration when it helps establish the
subject; do not add unrelated decorative widgets.

## Build and inspect the study desk

Create records and views before composing the home. Use the connection's current
formatting and view documentation. Preserve existing page and database identities
when arranging blocks, and read back the saved hierarchy after moving them.

Set page width, course-card size, text wrapping, and property visibility
intentionally. Put assignment due dates and status near the title; keep secondary
metadata in details. Embed real database views for working surfaces and reserve
page links for navigation. Hide duplicate database titles.

Open the home with the sidebar visible. Check that the learner can identify this
week's priority, choose a course, and read the next deadlines without a long
scroll. Open a course, then an assignment, and follow the route home. Inspect the
Calendar and Completed views; confirm completed work leaves Upcoming and undated
work remains discoverable. Restore the everyday view before delivery.

Check the result for card density, subject identity,
side-column balance, and reading comfort. Correct clipped dates, unreadable
cards, awkward wrapping, and excessive setup prose. A page with working links but
no substantive course material or clear study workflow is not complete.
