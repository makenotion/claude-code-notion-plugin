# Weekly project digest evaluations

Follow the [shared evaluation protocol](../../evaluations.md). These scenarios
specify tool fixtures and observable outcomes; they are not runtime instructions.

| Fixture                                                      | Capability           | Main checks                                                              |
| ------------------------------------------------------------ | -------------------- | ------------------------------------------------------------------------ |
| [period-delta.json](period-delta.json)                       | Period comparison    | Actual completion evidence, continuing blockers, merged versus released  |
| [first-snapshot.json](first-snapshot.json)                   | Missing history      | Useful snapshot, disclosed partial coverage, no invented trend           |
| [update-existing-digest.json](update-existing-digest.json)   | Saved rerun          | Same project-period record, correct relation, preserved commentary       |
| [pagination-and-conflict.json](pagination-and-conflict.json) | Counts and conflicts | Full population, explicit disputed closure, no unauthorized task changes |

Require evidence for period claims and correct population definitions before
comparing efficiency. A brief answer must still disclose material gaps. Additional
audience tests should ensure an external update does not expose internal source
details or links.
