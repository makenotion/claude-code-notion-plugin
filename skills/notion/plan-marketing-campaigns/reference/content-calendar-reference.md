# Content calendar reference

[Basic Content Calendar by Notion](https://www.notion.com/templates/content-calendar)
is a starting point for tracking content with an author, content type, production
status, and publication date.

Use this model for the shared Content destination. Add campaign relations and
format-specific working drafts as the brief requires. The composition guidance
in this skill is a recommended adaptation, not an inventory of the template's
exact blocks or views.

When an exact gallery layout is requested, inspect the current preview or
accessible source and explain any inaccessible portions. Community designs are
also eligible inspiration; see [design guidance](design.md). Honor explicit user
source restrictions and verify creator attribution when selecting a reference.
